======
RULES 
====== 

([ Moving Player | Follower ] -> [ Moving Player | Moving Follower ])

[> Player] [AngryQueen] -> RESTART

[ > Player | Pushable ] -> [ > Player | > Pushable ]
[ < Player | Pullable ] -> [ < Player | < Pullable ] 

[ Sight ] -> []
[ NWMirror1 ] -> [NWMirror]

startLoop

late HORIZONTAL [HSightSource1 | No Opaque No Queen1 ] -> [HSightSource1 | HSight1]
late VERTICAL [VSightSource1 | No Opaque No Queen1 ] -> [VSightSource1 | VSight1]
late HORIZONTAL [HSightSource2 | No Opaque No Queen2 ] -> [HSightSource2 | HSight2]
late VERTICAL [VSightSource2 | No Opaque No Queen2 ] -> [VSightSource2 | VSight2]

late RIGHT [HSightSource1 | NWMirror ] -> [HSightSource1 | NWMirror1 ]
late DOWN [VSightSource1 | NWMirror ] -> [VSightSource1 | NWMirror1 ]
late UP [NWMirror1 | No Opaque No Queen1 ] -> [NWMirror1 | VSight1] 
late LEFT [NWMirror1 | No Opaque No Queen1 ] -> [NWMirror1 | HSight1] 

endLoop

late [Sight Queen] -> [AngryQueen] message What is *SHE* doing here?
(
late [Sight1 Queen2] -> [AngryQueen] message What is *SHE* doing here?
)

No AngryQueen
All Queen1 on Target1
All Queen2 on Target2
