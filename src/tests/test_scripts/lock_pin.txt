======
RULES
======

[ tmp ] -> []

[ > player | pin ] -> [ player | pin ouch ] sfx0

(allow free movement along tunnels)
[ > player | path ] -> [ | player path ] 

(initiate mega-block push)
[ > player | blockA ] [ blockA ] -> [ > player | > blockA ] [ > blockA ]
[ > player | blockB ] [ blockB ] -> [ > player | > blockB ] [ > blockB ]
[ > player | blockC ] [ blockC ] -> [ > player | > blockC ] [ > blockC ]

(collision detection)
[ > blockX | wall ] -> cancel (silent)
left [ > lockA | pin ] -> [ > lockA | pin ok ] 
down [ > lockB | pin ] -> [ > lockB | pin ok ] 
right [ > lockC | pin ] -> [ > lockC | pin ok ] 
right [ > lockA pin ] -> [ > lockA ok pin ] 
up [ > lockB pin ] -> [ > lockB ok pin ]
left [ > lockC pin ] -> [ > lockC ok pin ] 
[ > restricted | pin no ok ] -> [ restricted | pin ouch ] 
[ > restricted pin no ok ] -> [ restricted pin ouch ] 

[ > solid | pin ] -> [ solid | pin ouch ] 
[ > blockA | notA ] -> [ blockA | notA ouch ] 
[ > blockB | notB ] -> [ blockB | notB ouch ] 
[ > blockC | notC ] -> [ blockC | notC ouch ] 
[ ouch ] [ > movable ] -> [ ouch ][ movable ] sfx0
[ ouch ] [ restricted ok ] -> [ ouch ] [ restricted ]

late [ pin lock ok ] -> [ pin lock ok ] sfx1
late [ anim ] -> [ anim ] again

WINCONDITIONS

no anim
