======
RULES
======

(push stars)
[ > Player | Star ] -> [ > Player | > Star ]


(dissolve animation)
[ Dissolve4 TreeDissolveCopy ] -> []
[ Dissolve3 ] -> [ Dissolve4 ]
[ Dissolve2 ] -> [ Dissolve3 ]
[ Dissolve1 ] -> [ Dissolve2 ]
[ Dissolve0 ] -> [ Dissolve1 ]



(stars protect trees below them)
late [ ProtectedTree ] -> []
late down [ Star | TreeTrunk ] -> [ Star | TreeTrunk ProtectedTree ]
late down [ ProtectedTree | TreeTrunk ] -> [ ProtectedTree | ProtectedTree TreeTrunk ]

(stars kill unprotected trees)
late [ star | Treetrunk no ProtectedTree ] -> [ star | TreeTrunkDissolveCopy Dissolve0 ] sfx1
late [ TreeTop TreeTrunkDissolveCopy ] -> [ TreeTopDissolveCopy ]


(tree top sprite)
late [ TreeTop ] -> []
late up [ TreeTrunk | no TreeTrunk ] -> [ TreeTrunk TreeTop | ]

(check if stars have a tree)
late down [ UnsatisfiedStar | TreeTop ] -> [ SatisfiedStar | TreeTop ]
late down [ SatisfiedStar | no TreeTop ] -> [ UnsatisfiedStar | ] 



(score stuff)
late [ Score ] -> []
late right [ SatisfiedStar no TempCountedStar ][ ScoreStart | no Score ] -> [ SatisfiedStar TempCountedStar ][ ScoreStart | ScoreSatisfied ]
late right [ SatisfiedStar no TempCountedStar ][ Score | no Score ] -> [ SatisfiedStar TempCountedStar ][ Score | ScoreSatisfied ]
late right [ UnsatisfiedStar no TempCountedStar ][ ScoreStart | no Score ] -> [ UnsatisfiedStar TempCountedStar ][ ScoreStart | ScoreUnsatisfied ]
late right [ UnsatisfiedStar no TempCountedStar ][ Score | no Score ] -> [ UnsatisfiedStar TempCountedStar ][ Score | ScoreUnsatisfied ]
late [ TempCountedStar ] -> []

[ action Player ][ ScoreStart no ScoreToggled ] -> [ Player ][ ScoreStart ScoreToggled ] 
[ action Player ][ ScoreStart ScoreToggled ] -> [ Player ][ ScoreStart ] 
late [ Score ][ ScoreToggled ] -> [ ][ ScoreToggled ]
