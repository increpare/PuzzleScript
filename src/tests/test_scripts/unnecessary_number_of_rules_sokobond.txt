RULES 
======

[Helium no Orbital] -> [Helium 0Electron]
[Hydrogen no Orbital] -> [Hydrogen 1Electron]
[Oxygen no Orbital] -> [Oxygen 2Electron]
[Nitrogen no Orbital] -> [Nitrogen 3Electron]
[Carbon no Orbital] -> [Carbon 4Electron]

[> Player Atom] -> [> Player > Atom]

Up [ Moving Atom UBond | Atom] -> [ Moving Atom UBond | Moving Atom]
+ Left [ Moving Atom LBond | Atom] -> [ Moving Atom LBond | Moving Atom]
+ Right [ Moving Atom RBond | Atom] -> [ Moving Atom RBond | Moving Atom]
+ Down [ Moving Atom DBond | Atom] -> [ Moving Atom DBond | Moving Atom]
+ [> Atom | Atom] -> [> Atom | > Atom]

[ > Atom AtomStuff] -> [> Atom > AtomStuff]

[ > Atom | Wall] -> Cancel

Late Right [Electron no Temps no RBond|Electron no Temps no LBond] -> [Electron Temp1|Electron Temp2 Sfx1] (Bond horizontally.)
+ Late [Temp1 no Bond] -> [Temp3 BondR]
