======
RULES
======
 
[ HunterL ] [ Stationary Player ] -> [ Left HunterL ] [ Stationary Player ]
[ > HunterL | Wall ] [ Stationary Player ] -> [ < HunterR | Wall ] [ Stationary Player ]
[ HunterR ] [ Stationary Player ] -> [ Right HunterR ] [ Stationary Player ]
[ > HunterR | Wall ] [ Stationary Player ] -> [ < HunterL | Wall ] [ Stationary Player ]
[ Hunter | ... | Player ] [ Stationary Player ] -> [ > Hunter | ... | Player ] [ Stationary Player ]
[ > Hunter | Player ] [ Stationary Player ] -> restart
[ > Hunter | Crate ] -> [ > Hunter | > Crate ]
 
 
[ > Character | Crate ] -> [ > Character | > Crate ]
[ Action Player | BlueCrate ] -> [ Action Player |GhostCrate ]
[ Action Player | RedCrate ] -> [ Action Player | ]
[ > Crate | CatWalk ] -> [ Crate | CatWalk ]
Up [ Catwalk | BackgroundTrue no Wall] -> [CatU Catwalk |backgroundTrue no Wall]
Down [ Catwalk | BackgroundTrue no Wall] -> [CatD Catwalk |backgroundTrue no Wall]
Left[ Catwalk | BackgroundTrue no Wall] -> [CatL Catwalk |backgroundTrue no Wall]
Right [ Catwalk | BackgroundTrue no Wall] -> [CatR Catwalk |backgroundTrue no Wall]
[ Holes ] -> [ Random Hole ]
