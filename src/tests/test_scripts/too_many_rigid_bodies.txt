=====
RULES
=====

right [ Box1 no BoxE | Box1 no BoxW ] -> [ Box1 BoxE | Box1 BoxW ] 
down [ Box1 no BoxS | Box1 no BoxN ] -> [ Box1 BoxS | Box1 BoxN ] 
right [ Box2 no BoxE | Box2 no BoxW ] -> [ Box2 BoxE | Box2 BoxW ] 
down [ Box2 no BoxS | Box2 no BoxN ] -> [ Box2 BoxS | Box2 BoxN ] 
[ BoxSpawn ] -> [ Box ]

[ > Player | Box ] -> [ > Player | > Box ]

startloop

[ > Box stationary BoxDir ] -> [ > Box > BoxDir ]

up [ moving BoxN | stationary Box ] -> [ moving BoxN | moving Box ]
right [ moving BoxE | stationary Box ] -> [ moving BoxE | moving Box ]
down [ moving BoxS | stationary Box ] -> [ moving BoxS | moving Box ]
left [ moving BoxW | stationary Box ] -> [ moving BoxW | moving Box ]

[ > Box | Box ] -> [ > Box | > Box ]

endloop

[ > Box | Wall ] -> cancel
